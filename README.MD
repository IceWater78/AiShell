# AiShell

AiShell 是一款运行在 Windows 桌面上的运维终端软件，面向网络设备与服务器的日常运维、安全应急与故障排查场景。它把四类能力装进同一个窗口：
AiShell 主要目的是解决「让 AI 替你干活，而且干得放心」的问题。

## 能力总览

| 能力域 | 说明 |
|--------|------|
| 多协议终端 | SSH / Telnet / Serial / Rlogin / SFTP / VNC / Databases / ES / Splunk 以会话形式接入；同设备多连接、20+ 台并发 |
| AI 运维 Agent | 六种执行模式、确认卡把关、会话池跨设备/跨数据源协同、上下文压缩、事实库记忆 |
| 安全门控 Harness | 四级风险分类 + 意图校验 + 配额 + 黑白名单 + 全量审计，统一评估入口不可绕过 |
| 值守告警 | 常驻看门狗轮询日志源：内置 16 条入侵特征 + 自定义关键字 + 外置规则库（≤5000 条），命中分级分流 |
| 数据库工作台 | SQL / Redis / MongoDB / ES / Splunk 五种面板，浏览、只读查询、行级编辑、库级管理 |
| 文件管理 | SFTP 双栏文件管理器 + ZMODEM（rz/sz）拖拽传输 |
| 审计 | 全量 JSONL 落盘，审计查看器多维过滤，跨设备操作「目标 ← 来源」可溯 |
| 安全与隐私 | 凭据系统级加密不出主进程、原子落盘、白名单 IPC、发布产物混淆+字节码+原生插件三重加固 |
| 本地化 | 简体中文 / English 双语界面，Agent 输出语言跟随界面语言 |

## 功能说明

### 多协议终端与会话管理

- **协议**：SSH（默认）、Telnet、Serial（串口 Console）、Rlogin、SFTP（文件会话）、VNC（远程桌面）；另有数据库会话（MySQL / MariaDB / PostgreSQL / SQL Server / Redis / MongoDB）与 Elasticsearch、Splunk 查询源。
- **认证**：密码 / 私钥（含 passphrase）/ SSH Agent（Pageant 自动回退）/ 键盘交互认证；老设备 SSH 算法兼容开关（旧款交换机 KEX/CBC/DSS）。
- **并发规模**：20+ 台设备同时在线经压测验证；单设备最多 8 条连接、全局 64 条上限保护。
- **会话库**：侧栏文件夹分组、拖拽归类、三档排序、搜索过滤、会话复制/粘贴、快速连接（凭据不落盘）；会话配置与事实按会话独立文件存储，结构升级自动迁移。


### 终端体验

- **编码**：32 项全量终端编码（UTF-8 / GBK / GB18030 等），连接级随时切换，老设备中文不乱码；
- **分屏**：标签拖拽拆分、四向分屏、最多 6 窗格，窗格比例可调。
- **广播输入**：XShell 式同步键入到多台已选终端，逐成员独立分级审计。
- **个性化**：内置多套经典配色转译版，支持导入导出，界面可跟随终端配色、等宽字体与字体文件导入、字号快捷调节。
- **应用锁**：长时间未操作自动锁定，密码解锁；锁定期后台任务与 Agent 工作不受影响。
- **其他**：选中即复制、Ctrl+F 查找、会话日志、导出屏幕、快捷命令一键发送、快捷键自定义。

### AI 运维 Agent

**基本形态**：连上设备后在 Agent 栏用中文或英文描述需求，Agent 自动完成 查询 → 执行 → 回读验证 → 总结（Markdown 渲染）。同一会话的聊天历史与模式跨重连保留。

**六种执行模式**

| 模式 | 行为 |
|------|------|
| 计划模式 | 只读诊断：查询自动执行，任何变更不执行，仅产出计划供参考 |
| 变更确认（默认） | 查询自动执行；每条变更弹确认卡，批准才执行 |
| 自动编辑 | 查询与普通变更自动执行；危险命令仍弹卡 |
| 完全托管 | 除禁止级外全自动；计划外命令、本轮未表达的变更仍会确认 |
| 安全应急 | 攻击事件处置专项：进程/网络/日志/持久化多线取证、IOC 提取、威胁情报比对 |
| 故障处理 | 根因定位专项：应用/数据库/中间件/系统四线采集，直达「根因 + 复现步骤」结论 |

**确认卡（把关入口）**：命令按目标设备的厂商画像四级分级——安全级（查询）自动执行；变更级弹卡确认；危险级（重启、删除等）红色强确认；禁止级（格式化、擦闪存、安装软件包等）必须逐字输入命令原文才能解锁，任何模式都不豁免。在此之上叠加硬约束：意图范围校验（计划外变更强制确认）、意图声明校验、先读后写、单轮命令与变更配额、禁止多命令串联与命令替换等走私形态、未知命令按变更级处理。管控策略可在 AI 管控中自定义（黑白名单正则、各级处置、严格/标准/宽松预设）。

**安全应急防护三档**：A 只读取证（默认）/ B 实时告警（持续监视命令输出中的入侵特征）/ C 自动防护（命中高危特征时 fail-closed 拦截危险命令，只读排查继续推进）。

**会话池（跨设备协同）**：一次对话纳管多台终端设备与数据库/ES/Splunk 数据源，Agent 自动选靶执行；风险分级跟随目标设备的画像，跨设备确认卡带目标徽标，审计标注「目标 ← 来源」；成员断连置灰、重连自动恢复。

**模型接入**：任意 OpenAI 兼容接口与 Anthropic Messages 双格式（GLM、DeepSeek、Kimi、通义、OpenAI、Ollama / vLLM 内网自部署等）；API Key 加密落盘、仅主进程解密使用；每个模型可单独配置超时与思考深度，支持连通性测试。

### 值守告警

值守是独立于 Agent 模式的会话级开关：开启后主进程常驻看门狗按设定间隔（30 秒–1 小时，多会话错峰）轮询设备日志源；Agent 执行轮次期间自动让位、结束后续读，既不打扰也不遗漏。

- **日志源**：Linux / Windows 常见日志路径自动探测，支持自定义路径；断线续读、日志回绕自动归零。
- **检测能力**：
  - 内置 16 条入侵特征绊线（webshell、隧道、提权、持久化等），每条附核查清单；
  - **自定义关键字**：最多 32 条，字面匹配、大小写不敏感——运维找关键信息不用写正则；
  - **外置规则库**：全局规则库至多 5000 条，字面规则走 Aho-Corasick 单遍匹配（扫描耗时与规则数量解耦，扩到千条同级），正则规则保留人工策展入口；内置 16 条为不可覆盖基线；
  - **规则分析**：粘贴一篇威胁情报网页地址，软件抓取内容后交大模型加工为规则候选（含正反测试样本与置信度），AI 预筛后人工勾选批量入库——把公开情报沉淀为自有规则库；仅接受公网 http/https 地址（环回/内网/保留地址一律拒绝），抓取、分析、入库全程审计。
- **管理界面**（V2.4 新增）：设置 → 规则库统一管理（新增/编辑/启停/删除、正反样本自检、条数计数），值守卡一键跳转；Agent 溯源结论卡可一键沉淀为规则。

规则库有三个写入口径——手动管理、溯源结论沉淀、规则分析——全部经人工确认闸；且自定义与外置规则只作用于值守告警层，永不进入 Agent 命令门控链路：规则加得再多，也不会改变 Harness 对命令风险的判定。

### 数据库工作台

- **面板形态**：SQL 工作台（库/表折叠树 + SQL 编辑区 + 结果网格）、Redis 键浏览器、MongoDB 文档浏览、ES / Splunk 查询面板。
- **数据操作**：只读查询自由执行；行级编辑（增/删/改行）按主键生成参数化语句并弹确认卡，无主键表禁编辑；删列等 DDL 走暂存确认、一步可撤；库级管理（重命名/复制/删除/导出）等高危操作需逐字输入解锁。
- **Agent 协同**：故障处理模式下 Agent 可执行自由只读 SQL（写操作与可疑语句一律拒绝），结果与人工工作台同源。

### 文件管理

- **SFTP 双栏文件管理器**：本地浏览 + 远端上传/下载/新建/重命名/删除，拖拽传输、键盘操作、同名覆盖确认；远端操作限定在登录目录树内，防越权路径。


### 审计

所有操作全量落盘：手动键入、广播、快捷命令、Agent 自动执行、你批准的、被拒绝的、被拦截的，以及系统事件（连接/断开/文件传输/规则抓取与入库）。审计查看器支持按会话、来源、风险级、关键词、日期范围过滤；跨设备命令显示「目标 ← 来源」；审计/日志/数据目录一键直达。

### 模型与集成

- **模型管理**：多模型并存快捷切换，OpenAI 兼容与 Anthropic 双格式，连通性测试，按模型超时配置。
- **威胁情报**：内置支持 8 家国内外威胁情报源 API Key 接入，密文保存，IOC 自动比对。

## 安全设计

| 维度 | 设计 |
|------|------|
| 凭据保护 | 密码/passphrase/API Key 系统级加密落盘；明文仅主进程瞬时使用，界面只见掩码；一次性凭据不落盘 |
| 进程边界 | 主进程持有全部连接与凭据；渲染层与主进程仅经白名单 IPC 通道通信 |
| 命令门控 | 所有 Agent 命令经统一风险评估入口，四种执行模式都不得绕过；禁止级逐字输入 + 双层校验；命令串联/命令替换/进程替换等走私形态全部封堵 |
| 规则隔离 | 自定义关键字与外置规则库仅作用于值守告警层，不进入 Agent 命令门控链路 |
| 落盘安全 | 所有配置「临时文件 + 原子替换」，断电不留半截文件；结构变更走迁移纯函数并配测试 |
| 防篡改 | 发布产物经 JavaScript 混淆 + 主进程 V8 字节码化 + 自研原生插件三重加固，asar 封装不含调试符号，程序目录零用户数据 |
| 激活体系 | 本机硬件指纹生成校验码 → 邮箱获取激活码激活；激活状态绑定本机，每次启动自动复核 |
| 外部输入面 | 规则分析仅接受公网 http/https 地址（拒绝环回/内网/保留地址）；数据库访问参数绑定防注入，ES 端点白名单，Splunk 只读 |


## 运行环境与安装

- **操作系统**：Windows 10 / 11（64 位）；无需预装任何运行时。
