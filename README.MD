AiShell 是一款面向运维人员的多协议智能终端，内置可管控 AI 运维 Agent，支持多设备并发、分屏、批量广播与文件传输。

## ✨ Features

- **多协议终端**：SSH / Telnet / Rlogin / Serial / SFTP / VNC等多协议支持；SSH 支持密码、私钥、SSH Agent、键盘交互认证，提供老旧设备 SSH 算法兼容开关
- **多设备并发**：最多 20+ 设备同时在线，单设备支持多条独立标签会话，全局连接上限 64；支持广播输入同步下发命令
- **分屏与文件**：二叉树拖拽分屏；ZMODEM传输，双栏 SFTP 文件管理；单连接独立编码切换
- **会话管理**：JSON 持久化会话，逐连接会话日志，可自定义日志路径
- **AI 运维 Agent**：侧边自然语言对话，AI 操作回显在终端；Harness 管控：步数配额、危险命令确认、正则黑白名单、四级风险策略，全量审计
- **设备识别**：自动识别华为 VRP / 华三 Comware / 思科 IOS / 通用设备，加载对应命令与危险规则；内置事实库记录设备信息
- **个性化**：配色、字体、字号、鼠标行为可配置，配色方案支持导入导出
